// fonctionnalités

Ce que KayroBot fait pour toi

Les tâches qui prennent du temps quand on gère un serveur, réunies dans un seul bot.

Une modération complète

Bannir, débannir, expulser, mettre en sourdine, nettoyer un salon, activer le mode lent ou verrouiller un salon. Le membre sanctionné est prévenu en message privé.

  • Avertissements enregistrés pour chaque membre
  • Sourdine automatique d'une heure au troisième avertissement
  • Le bot respecte la hiérarchie des rôles

Un tableau de bord web

Choisis ton serveur, envoie un message, poste un embed ou sanctionne un membre depuis ton navigateur.

Ouvrir le dashboard

Des tickets filtrés par le staff

Le membre remplit un court formulaire. Le staff accepte ou refuse, et le salon privé n'est créé qu'à l'acceptation.

FormulaireStaffSalon privé

Un serveur prêt en une commande

/serveur crée les catégories et salons publics, privés, vocaux, tickets et staff. Un regret ? /serveur-annuler supprime ce qu'il a créé.

Des messages programmés

Choisis une date et une heure de Paris, le bot publie le message au bon moment. Tu peux les lister et les annuler.

Un rappel de bump toutes les 2 heures

Le bot ping le rôle de ton choix quand il est temps de relancer ton serveur sur les listes publiques.

Une apparence à ton image

Donne un autre nom et une autre photo au bot dans ses messages, sans toucher à son vrai profil.

// commandes

Toutes les commandes

Tape / dans Discord, puis le nom de la commande. L'autocomplétion de Discord te guide pour les options.

Les paramètres indiqués résument les champs et réglages identifiables depuis le site. Les options exactes proposées par Discord peuvent varier selon la commande et restent visibles dans son menu de saisie. Lance /aide pour la liste, ou /aide-plus pour une explication par commande.

// aide

Besoin d'aide ?

Pour bien démarrer, puis les questions qu'on se pose le plus souvent.

  1. Invite le botClique sur « Inviter » et choisis ton serveur. Il faut être administrateur.
  2. Place son rôle assez hautDans Paramètres du serveur > Rôles, monte le rôle de KayroBot au-dessus des rôles qu'il doit gérer.
  3. Configure ce dont tu as besoin/serveur pour créer la structure, /ticket config (ou le dashboard) pour les tickets, /bump-auto activer pour le rappel de bump.
  4. Ouvre le dashboardConnecte-toi avec Discord pour gérer ton serveur depuis le navigateur.
Le bot dit qu'il n'a pas la permission

Son rôle est placé plus bas que celui du membre ou du rôle visé. Monte le rôle de KayroBot dans Paramètres du serveur > Rôles, puis réessaie.

Le bouton du panneau de tickets répond que rien n'est configuré

Lance /ticket config dans Discord, ou ouvre l'onglet Tickets du dashboard, pour choisir le salon où arrivent les demandes et le rôle du staff. Ensuite, poste le panneau avec /ticket panneau.

Qui peut utiliser les commandes ?

Chaque commande demande une permission Discord. Par exemple, /say et /embed demandent Gérer les messages, /role demande Gérer les rôles et /serveur demande d'être Administrateur.

Je ne vois pas mon serveur dans le dashboard

Seuls les serveurs où tu es propriétaire ou administrateur apparaissent. Si le bot n'y est pas, le dashboard affiche « Bot absent » avec un bouton pour l'inviter.

Un membre n'a pas reçu le message privé de sanction

Si ses messages privés sont fermés, Discord refuse l'envoi. La sanction s'applique quand même.
